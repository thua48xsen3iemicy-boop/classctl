# Координатор

Хранит отдельно инвентарь мест, назначения преподавателей и журнал операций. Потеря heartbeat меняет состояние узла. Изменение инвентаря требует административной операции. Координатор получает identity из аутентифицированного соединения. При каждом открытии просмотра, включении управления и выполнении действия заново разрешает nodeId через текущие место и аудиторию. При изменении назначений отзывает подписки и разрешения.

Потоки миниатюр ограничивать по числу подписчиков и видимых мест. Для каждого выхода хранить в памяти последний кадр активной сессии и метку проверки. Удалять при выходе, отзыве доступа и истечении политики хранения. В журнал писать запрос и исход по каждой цели. Последовательность запуска описана в [архитектуре](../docs/architecture.md).
