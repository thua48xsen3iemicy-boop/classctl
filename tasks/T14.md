# T14. Подписи компьютеров и пользователей FreeIPA

Портал преподавателя подписывает компьютеры постоянным идентификатором из инвентаря. Для активной графической сессии рядом с ним показывается полное имя из GECOS. Порядок мест определяется прежним инвентарём.

Процесс сессии получает запись текущего UID через NSS и добавляет необязательное поле `displayName` в ответ `session.identity.v1`. Агент передаёт ответ координатору. Координатор владеет схемой ответа и передаёт имя браузеру через `/state` только для совпадающей активной сессии. Старые источники продолжают передавать метаданные прежней формы. При отсутствии GECOS или при работе со старым источником портал показывает идентификатор компьютера. Старый координатор игнорирует новое поле.

Приёмка выполняется командами `python3 checks/verify.py` и `python3 server/live_acceptance.py`. На синтетическом стенде проверить имя из GECOS, прежний источник, несовпадение hostname с идентификатором из конфигурации и очистку имени после выхода. В реальной аудитории сверить поле GECOS из `getent passwd <логин>` на ученическом ПК с подписью в портале, затем сменить пользователя KDE и проверить обновление имени.
