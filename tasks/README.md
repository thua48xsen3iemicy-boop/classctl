T01, T02 и T03 используют готовую схему только для чтения и пишут в разные каталоги. После T02 автор T06 работает в server/, пока T04 единолично ведёт контракт. T05 объединяет потребителей после слияния обеих работ. T07 и T08 развести по времени в общей части браузера и сервера. T09 ведёт измерения на зафиксированной версии.
