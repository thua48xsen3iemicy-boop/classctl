# T17. Портал преподавателя во «Внешних сайтах» Nextcloud

Администратор указывает адрес Nextcloud в необязательном поле `nextcloud_origin` JSON-инвентаря. Ops владеет форматом инвентаря. Установщик записывает адрес в локальную политику координатора. Координатор использует его для `frame-ancestors` на странице портала. Старые инвентари без этого поля и значение `null` сохраняют запрет на встраивание. Сетевой контракт v1 сохраняется.

`python3 ops/ssh/deploy.py --check ops/ssh/inventory.example.json` проверяет инвентарь автономно. Полный сценарий `python3 server/live_acceptance.py` проверяет отказ при встраивании без настройки и с другого адреса, получение миниатюр и выход в полноэкранный просмотр внутри тестовой HTTPS-страницы.

На стенде разверните кабинет по [инструкции](../ops/ssh/README.md), откройте «Внешний сайт» в Chromium на учительском ПК и проверьте миниатюры и полноэкранный просмотр с фактическим адресом Nextcloud и настройками браузера.
