# T12. Развёртывание по SSH

Администратор задаёт состав одной аудитории. Скрипт на его рабочей станции доставляет зафиксированную ревизию Git и индивидуальные сертификаты. Координатор получает существующие форматы room и policy, узел использует проверку login1, преподаватель получает права из явного списка. Владелец формата инвентаря установки — ops. Сетевой контракт v1 сохраняется. Установка через SSH предназначена для машин, где эти ресурсы ещё не ведёт Puppet.

Приёмка: проверить пример инвентаря автономно, установить на пилотный класс, повторить установку, сверить отпечатки и проверить реальный вход KDE и браузера по [инструкции](../ops/ssh/README.md).
