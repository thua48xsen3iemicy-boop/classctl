# T12. Развёртывание по SSH

Администратор задаёт состав одной аудитории. Скрипт на его рабочей станции доставляет зафиксированную ревизию Git и индивидуальные сертификаты. Координатор получает существующие форматы room и policy, узел использует проверку login1, преподаватель получает права из явного списка. Владелец формата инвентаря установки — ops. Сетевой контракт v1 сохраняется. Установка через SSH предназначена для машин, где эти ресурсы ещё не ведёт Puppet.

Приёмка: проверить пример инвентаря автономно, установить на пилотный класс, повторить установку, сверить отпечатки и проверить реальный вход KDE и браузера по [инструкции](../ops/ssh/README.md).

Ученические места принимают сменяемых пользователей KDE/X11 на seat0. Инвентарь связывает машину с местом через SSH-адрес и nodeId. Поле user из ранее заполненного инвентаря допускается при обновлении. Производитель комнат и потребители room и policy прежние. В SSH используется учётная запись администратора.

Приёмка смены пользователя: на одном месте войти под первым учеником, завершить или переключить его сессию и войти под вторым. Убедиться, что прежнее изображение и управление закрываются, а карточка того же места показывает второго ученика. Проверить отказ SDDM, SSH и неактивной сессии.

Приёмка расширения аудитории: добавить узел в students, сохранив прежние записи, и повторить развёртывание. Проверить новое место, неизменность старых мест и сохранность журнала. Повторить с тем же списком и убедиться, что место не дублируется. Проверка на временной SQLite выполняется командой `python3 server/acceptance.py`.
