# T10. Выбор компьютеров в гриде

После T05 браузер преподавателя строит список компьютеров из room.seats в существующем ответе координатора /state. Формат состояния и сообщений подписки сохраняется. Выбор хранится в браузере отдельно для каждой аудитории.

Приёмка: открыть панель, скрыть компьютер с несколькими мониторами, проверить закрытие его подписок и сохранение остальных. Скрыть все машины, вернуть одну, обновить страницу. На физическом стенде проверить возврат из крупного просмотра, завершение управления и скрытие машины в гриде.
