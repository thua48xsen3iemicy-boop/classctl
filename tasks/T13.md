# T13. Прокрутка при удалённом управлении

Браузер передаёт шаги вертикального колеса с координатами указателя. Координатор проверяет их по схеме событий и пересылает в активную сессию управления. X11-агент переводит их в нажатия и отпускания кнопок колеса.

Владелец [схемы событий](../contracts/input-v1.schema.json) в этой задаче — компонент координатора. Расширение `control.wheel.v1` объявляет агент. Координатор сообщает о нём браузеру только для доступных узлов. При смешанных версиях просмотр, клавиши и кнопки продолжают работать по `classctl.input.v1`. Прокрутка доступна после обновления координатора и агента.

Проверить схему, прокрутку вверх и вниз через XTEST, ограничение числа шагов и обработку поля за пределами изображения. На Calculate прокрутить терминал на выбранном мониторе под правами управления.
