# Установка в одну аудиторию по SSH

Запускайте из корня рабочей копии на компьютере администратора. Нужны Python 3.10+, git, OpenSSH и OpenSSL. Цели должны быть явно записаны в known_hosts, доступны по ключу как root либо иметь sudo без пароля для установки. Понадобятся настроенные DNS и сеть: узлам нужен адрес координатора на TCP-порту из инвентаря, для WebRTC нужен маршрут ICE. Реализация рассчитана на прямую связь в LAN.

1. Скопируйте пример и замените адреса SSH, DNS или IPv4 координатора, имена существующих локальных пользователей и идентификаторы мест. SSH-алиасы могут задавать нестандартный порт. Список students задаёт порядок мест в одном ряду. Укажите выделенный учительский ПК в coordinator. Права локального портала задаются в rights для всего кабинета: view или view и control. Поле port задаёт порт агентов, ui_port — порт браузера на 127.0.0.1.
2. Проверьте инвентарь и выполните установку.

```sh
cp ops/ssh/inventory.example.json /tmp/classctl-room.json
# Отредактируйте /tmp/classctl-room.json перед выполнением команд ниже.
python3 ops/ssh/deploy.py --check /tmp/classctl-room.json
python3 ops/ssh/deploy.py /tmp/classctl-room.json
```

Код служб берётся из HEAD локального Git. Для доставки новых изменений служб сначала зафиксируйте их. Координатор и узлы клонируют локально переданный bundle. Python-зависимости устанавливаются из настроенного индекса pip в окружение конкретной ревизии. Скрипт устанавливает системные пакеты через apt (Debian) или emerge (Calculate). В других дистрибутивах подготовьте зависимости самостоятельно. Нужны системный Python с venv и pip (рекомендуется 3.12), OpenRC или systemd, на местах — работающие KDE/X11, elogind или systemd-logind с busctl, xrandr, xkbcomp и Pillow с XCB. На учительской машине нужны Chromium и curl.

Храните каталог CA (по умолчанию ~/.local/state/classctl) с правами 0700, сделайте защищённую резервную копию. Используйте отдельный --state для каждой аудитории. Повторный запуск использует ключи узлов и сертификаты с остатком срока более 30 дней. Обновление перезапускает службы. SQLite и журнал сохраняются; при изменении существующей рассадки скрипт остановится перед заменой политики. Назначения в policy.json целиком определяет текущий инвентарь. Не управляйте теми же файлами одновременно из Puppet или другого рабочего места.

Скрипт проверяет /state на loopback учительского ПК и ждёт online всех перечисленных узлов. После установки войдите заново в KDE/X11 на одном месте и откройте выведенный локальный HTTP-адрес в Chromium учительского ПК. Сверьте изображения обоих мониторов, права кабинета и исчезновение изображения при выходе ученика. Подробности [физической приёмки](../live.md).
