# Развёртывание и приёмка

Puppet должен доставлять пакет системной службы, OpenRC init-скрипт, адрес координатора, доверенный CA, индивидуальную идентичность узла, список разрешённых действий и автозапуск KDE. Закрытый ключ доступен только службе. При замене ПК администратор перепривязывает узел к прежнему месту и отзывает прежний сертификат. Обновление начать с одного места. При несовместимых версиях вернуть предыдущий пакет и проверить восстановление heartbeat и инвентаря.

Для приёмки записать версии Calculate, Xorg, браузера и видеодрайвера, фактический вывод xrandr, топологию LAN и тип ICE-пары. Проверить загрузку до логина, два выхода, поворот, зеркалирование, выход из KDE и повторный вход. Сопоставить видимое в браузере с физическими мониторами. Проверить доступность управляющего адреса и учебных сервисов при действующей интернет-политике. Порядок работ задаёт [очередь](../tasks/README.md).
