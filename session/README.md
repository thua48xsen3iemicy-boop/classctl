# Компонент физической X11-сессии

Запускается с DISPLAY и Xauthority пользователя из автозапуска KDE. Перечисляет активные выходы XRandR и сообщает прямоугольники в координатах корневого окна после применения поворота. Изображение монитора уже ориентировано как на столе. Повторное вращение координат в браузере дало бы неверный ввод. rotation хранит поворот по часовой стрелке в градусах от нормального положения, адаптер переводит обозначения XRandR. Отражённые копии одного участка получают разные monitorId и общий mirrorGroup. При смене режима обновить перечень атомарно, увеличить ревизию и остановить ввод до нового выбора.

Процесс отвечает за захват, интерактивный трек и учёт локально зажатых клавиш и кнопок конкретного контроллера. Допускать одного контроллера на сессию. Проверка [T07](../tasks/T07.md) включает XKB, сочетания клавиш и потерю связи.
