# Браузер преподавателя

Ключ карточки — seatId, положение задают row и column из [инвентаря](../contracts/examples/room.json). При logout или offline место сохраняет подпись и положение. Каждая миниатюра показывает конкретный выход. Весь стол и отдельный монитор выбираются явно. Возврат из просмотра восстанавливает аудиторию и выбранное место. Клиент сообщает видимость карточек при прокрутке.

При object-fit: contain и центрировании измерить прямоугольник содержимого контейнера в CSS-пикселях. Для декодированного изображения W×H и контейнера Cw×Ch взять s=min(Cw/W, Ch/H), отступы ((Cw−sW)/2, (Ch−sH)/2). Вычесть начало контейнера и отступы из clientX/clientY, поделить на sW и sH. Точки вне полуоткрытого квадрата [0,1)×[0,1) отбросить. Для выхода (x,y,w,h) корневая точка равна (x+floor(u·w), y+floor(v·h)). Пример: кадр 1920×1080 в области 1000×1000 имеет вертикальные поля по 218,75 px; центр области даёт (960,540) относительно выхода. Для всего стола использовать охватывающий прямоугольник выходов и отбросить промежутки. Учитывать [ориентацию кадра](../session/README.md) и ревизию захвата.
