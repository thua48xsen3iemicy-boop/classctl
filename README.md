# classctl

Преподаватель открывает аудиторию в браузере, видит физические экраны рабочих мест Calculate Linux/KDE/X11 и явно выбирает место для управления. Сервер работает в сети учреждения. Конфигурацию узлов доставляет Puppet.

**Состояние проекта.** Сейчас запускается проверка инженерной основы. Она читает эталон аудитории, состояние двухмониторного места, запрос просмотра и частичный результат группового действия, проверяет связи между ними и вызывает безопасное демонстрационное действие. Первый интерфейс появится при выполнении [T01 — одно место в браузере](tasks/T01.md).

## Локальная проверка

Нужен Python 3.12 с модулями venv и pip. Из корня репозитория один раз подготовьте окружение (установка пакетов требует доступа к индексу Python или локальному зеркалу).

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-check.txt
```

Команда проверки в активированном окружении

```sh
python3 checks/verify.py
```

Код выхода 0 означает, что схемы, положительные и отрицательные примеры, связи эталонного сценария, демодействие и внутренние ссылки прошли проверку. [GitHub Actions](.github/workflows/check.yml) запускает ту же команду.
