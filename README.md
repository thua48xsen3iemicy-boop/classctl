# classctl

Преподаватель открывает аудиторию в браузере, видит физические экраны рабочих мест Calculate Linux/KDE/X11 и явно выбирает место для управления. Координатор на учительском ПК отдаёт локальный интерфейс и принимает агентов по mTLS из сети учреждения. Конфигурацию и обновления доставляют [роли Puppet](ops/puppet/README.md).

**Состояние проекта.** Преподаватель с правом control открывает управление щелчком по миниатюре монитора. [Настройка T07](ops/live.md). Для одного места работают живые миниатюры и крупный просмотр выбранного монитора через WebRTC. Проверены синтетический источник и виртуальный Xorg. Команды запуска и порядок физической приёмки приведены в [инструкции T05](ops/live.md). Отдельно доступны [браузерный стенд T01](web/README.md) и проверка контрактов.

## Локальная проверка

Нужны Node.js 18+ для проверки получателя превью и Python 3.12 с модулями venv и pip. Из корня репозитория один раз подготовьте окружение (установка пакетов требует доступа к индексу Python или локальному зеркалу).

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-check.txt
```

Команда проверки в активированном окружении

```sh
python3 checks/verify.py
```

Код выхода 0 означает, что схемы, положительные и отрицательные примеры, связи эталонного сценария, демодействие и внутренние ссылки прошли проверку. [GitHub Actions](.github/workflows/check.yml) запускает ту же команду.
