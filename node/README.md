# Системная служба

OpenRC поднимает службу до входа в KDE. Служба владеет ключом узла, исходящим управляющим соединением и локальным журналом дедупликации. На сокете пользовательского процесса проверяет peer credentials и принадлежность активной сессии локальному месту. Список работающих сессий сверяет с менеджером входа на стенде. При logout объявляет отсутствие графической сессии, сохраняя системные возможности.

Диспетчер допускает только доверенные установленные идентификаторы и проверяет параметры, срок и контекст перед вызовом. Для системных операций выдавать минимальные полномочия конкретному обработчику. [Демонстрация контракта](../actions/README.md) работает от обычного пользователя.
